Установка

```bash
# Создать виртуальное окружение
python -m venv .venv

# Активировать его
# Windows:
.venv\Scripts\activate
#Linux / macOS:
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

Приложение запускается через python app.py (порт 5000), страницы — / (мониторинг), /editor (разметка), /map (карта), /analytics (аналитика). Зависимости для запуска: Flask, OpenCV, NumPy, TensorFlow. 

Структура проекта

| Модуль | Назначение |
| --- | --- |
| `app.py` | Основной сервер: видеопоток, классификация, мониторинг |
| `editor_blueprint.py` | Редактор разметки парковочных мест |
| `map_blueprint.py` | Карта парковок |
| `analytics_blueprint.py` | Аналитика и графики |
| `db.py` | Работа с базой данных SQLite |
| `train_model.py` | Обучение нейросетевой модели |
| `test_model.py` | Тестирование и оценка точности модели |
| `models/parking_classifier.h5` | Обученная модель (включена в проект) |

Обучающий набор изображений (патчи парковочных мест) в репозиторий
не включён из-за большого объёма. Поэтому скрипт `train_model.py`
без папки с датасетом запускаться не будет — он нужен только для
воспроизведения процесса обучения, а не для работы приложения.
